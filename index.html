  2. 02.

    와이어프레임 및 정보 구조화 하기

    화면의 뼈대와 메뉴 구조를 설계하여, 사용자가 막힘없이 목적까지 이동할 수 있도록 합니다.

  3. 03.

    UI 디자인 만들기

    색상, 폰트, 이미지, 버튼 디자인을 적용해 완성된 '디자인 화면(시안)'을 만들어냅니다.

  4. 04.

    마크업 개발하기

    피그마 화면을 보면서 웹 브라우저가 읽을 수 있도록 글자, 이미지, 섹션 등의 HTML 코드 작성합니다.

  5. 05.

    스타일링 및 동적 구현하기

    CSS로 피그마 디자인과 반응형 화면을 구현하고, JS로 기본 인터랙션(버튼 동작 등)을 더합니다.
